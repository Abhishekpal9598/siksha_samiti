# Education Committee Competition — Documentation Pack

This pack contains eight Markdown specifications for the planned web application.

## Files
1. `01-PRD.md` — product scope and requirements
2. `02-TRD.md` — architecture and technical requirements
3. `03-APP-FLOW.md` — role navigation and workflows
4. `04-UI-UX.md` — responsive design specification
5. `05-BACKEND-API.md` — API and backend contracts
6. `06-DATABASE.md` — MongoDB collection schemas and indexes
7. `07-SECURITY.md` — security, privacy, and operational controls
8. `08-IMPLEMENTATION-PLAN.md` — phased build plan and Antigravity prompt

Read in numeric order. These are implementation specifications, not a claim that the application has already been built or tested.


**Decision update v1.1 (2026-10-19):** Result mode is Head-publishes-first; each student can then see only their own result. Test mode supports both Online MCQ and OMR as alternative routes; one registration can use one route and produce one final result. See PRD, Backend API, Database, and Implementation Plan for authoritative permissions and acceptance tests.
